## 目前最重要的 7 条结论

1. **FF14 比 WoW 更适合做放置游戏**。它原生就有雇员探险、岛屿庇护所、宇宙探索、深层迷宫、天书奇谭、
   任务轮盘、幻境武器长链等一整套"离线/周期"系统；7.56 更是直接推出了棋盘 roguelike 玩法
   **Crucible of the Unbroken**（编队 + 独立 HP + 一次性道具 + 永续装备 + 计分赛季）。

2. **8.0《Evercold》官方自己就在"去 MMO 化"**：推出 **Seasons / Adventure Activity**（每周自选进度途径，
   媒体解读为废除亚拉戈神典石）、**物品等级绑定角色而非职业**（Armoury Update）、副本难度改三档、
   战斗系统分 **Reborn / Evolved** 双模式（Evolved 强调"职业特色"）。
   等级上限 **100 → 110**，2027 年 1 月上线。

3. **内容曲线是线性的，且有固定章节模板**：每资料片 **+10 级 / +130 iLvl**；
   3.0 之后每章固定 **12 八人本 + 12 零式 + 3 个 24 人本 + 1~2 绝境战**。
   → 游戏可做成**可复用的章节模板**，只用数据填充就能扩到 8.0/9.0。

4. **不能照抄 wow-idle 的"招募无名冒险者"**。FF14 的正统解法是**光之战士 + 拂晓血盟**，
   官方 Duty Support/Trust 系统已经给了"NPC 队友参战"的合法性。
   且 FF14 **没有天赋树**，养成深度必须改从**职业量谱 / 特性 / 魔晶石 / 幻境武器**取。

5. **首批该做哪 8 个职业已确定**：**WAR / WHM / BLM / MCH / SMN / RDM / SGE / BST**
   —— 全是"单/双整数资源池 + 固定循环 + 无团辅或团辅极轻"。
   **占星最不建议正面还原**；**青魔建议换思路**做成"技能收集 + Build 解谜"。

6. **节奏设计要"照抄一半、反着做一半"**：照抄**四层结构**（无重置产线 / 每日次数 / 每周上限+清单 / 赛季排行）；
   但**不要抄 FF14 的 23:00 重置**（改本地 04:00–05:00），每周压到 3 天。
   FF14 全表 50+ 项周期性内容里**只有"兽栏训练"是小时级**——而那正是放置游戏的主场。

7. ⚠️ **法务是这个项目的最大风险，且"非商业 ≠ 安全"**：
   - 同形态先例存在（GitHub 上的 `Toxocious/FFXIV-Idle`，未见下架），但**仍属灰区**
   - **Melvor Idle 不能拿来类比**（它是原创 IP，与 RuneScape 只共享玩法结构）
   - 🔴 **不要内嵌任何 FF14 音乐**（2026-05-07 起全部原创乐曲已信托 JASRAC）
   - 🟠 **不要打包 XIVAPI / datamining 数据表**；数值体系应完全自研
   - 🟢 **Universalis 是唯一法律干净的数据源**（玩家上报，非解包）
   - 发布前须逐项打勾 `07` §6 的 **34 项自检表**

> 一句话：**"只借名词与玩法结构，数值与文本全部自研"是唯一稳妥的定位。**

## 研究方法说明

- 每个专题由**独立调研代理**完成，要求：英文官方源优先（na.finalfantasyxiv.com / Lodestone / 官方 press release
  / fanfest 官网），辅以 RPGFan、Icy Veins、Prima Games、Gamerant、ff14.consolegameswiki 等。
- 中文二手源（17173 等）已知存在机器翻译讹误，凡引用一律**单独标注并打 ❓**、附核实状态。
- 所有事实标注 **✅ 官方确认 / ⚠️ 媒体报道 / ❓ 未证实**，并记录**核实日期**。
- **跨文档一致性审计**：已修复的错误与尚存冲突统一登记在 `00-current-state.md` §2 与 §5.8。
- 机器可读数据（`data/*.csv`）均由脚本生成，可重跑复核；条目带官方链接可逐条验证。
