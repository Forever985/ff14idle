### 2.2 世界观前置【官方设定】

- **艾欧泽亚（Eorzea）**：海德林（Hydaelyn）星球上的一块大陆，三大都市国家为**格里达尼亚**（森都）、**利姆萨·罗敏萨**（海都）、**乌尔达哈**（砂都）。
- **加雷马帝国（Garlemald）**：北方伊尔萨巴德大陆的军事帝国，利用**魔导技术**与飞空艇征服了大半星球。其军队编制为"军团"，1.0 时期入侵艾欧泽亚的是**第VII军团**，2.0 时期则是**第XIV军团**。
- **蛮神（Primals）**：蛮族以大量水晶与狂热祈祷召唤出的以太实体。蛮神会**榨干大地的以太**，使土地荒芜、水源干涸——这是"蛮神问题"被视为全艾欧泽亚共同威胁的根本原因【官方/游戏内文本，参见 [ffxivstory 2.0「暁の血盟」](https://ffxivstory.net/story/a_realm_reborn/550/)】。
- **卫月达拉加布（Dalamud）**：艾欧泽亚上空的小型红色卫星。实为**古代亚拉戈帝国建造的人工天体**，内部封印着"古代蛮神"巴哈姆特。

### 2.3 陨石计划与第七灵灾的引爆⚠️

| 阶段 | 内容 |
| --- | --- |
| 计划发起 | 帝国第VII军团团长**奈尔·范·达纳斯（Nael van Darnus）**，人称"白鸦（White Raven）"，启动**陨石计划（Project Meteor / メテオ計劃）**：将卫月达拉加布坠落至艾欧泽亚，使其化为焦土 |
| 奈尔的真实目的 | 奈尔早已知道达拉加布是亚拉戈人工天体，并在推进计划过程中接触到内部的"那位大人"——**古代蛮神巴哈姆特**的意志。他真正想要的不是帝国征服，而是"净化一切生命" |
| 同盟成立 | 三大军民团首脑（**梅尔维布·布罗菲斯温**、**卡努·埃·塞纳**、**劳班·阿尔丁**）在不语仙的座桌签署防卫条约，成立**艾欧泽亚都市军事同盟 / 艾欧泽亚同盟军** |
| 帝国的内讧 | 第XIV军团团长**盖乌斯·范·巴埃萨**怀疑奈尔欺瞒皇帝，暗中向艾欧泽亚泄露"交信雷波塔"情报，借艾欧泽亚之手**间接肃清奈尔** |
| 交信雷波塔攻略 | 机工师**西德·南·加隆德（Cid nan Garlond）**解析情报，同盟军破坏卡斯特鲁姆·诺武姆的雷波塔 |
| 奈尔·德乌斯·达纳斯 | 雷波塔被毁后奈尔仍能控制卫月；他启动亚拉戈遗迹浮空岛，与达拉加布的"神意"融合，化为**奈尔·德乌斯·达纳斯（Nael deus Darnus）**，被同盟军精锐击败、肉体回归以太 |
| 卫月崩坏 | 奈尔虽死，达拉加布仍持续坠落。**救世诗盟盟主路易索瓦·露维耶（Louisoix Leveilleur）** 判断唯有举行**「神降ろし」（神降仪式）**，以民众的祈祷与海量以太召唤**艾欧泽亚十二神**之力方能阻止 |
| 第七灵灾 | 战场为摩杜纳东南的**卡尔提诺平原（Carteneau Flats）**。达拉加布外殻碎裂，**巴哈姆特自内部破封而出**，以**百万核爆（Megaflare）**蹂躏大地——这就是**第七灵灾** |
| 封印失败 | 路易索瓦以十二神的蓝色光之力束缚巴哈姆特，却在最后一刻**再封印失败** |
| 时间跳跃 | 路易索瓦动用**时神阿尔基克（Althyk）**之力，将一部份冒险者送入**「时限的狭间」**，送往 **5 年后**的世界。随后他被白光吞没，巴哈姆特亦消失——此后 5 年无人再见过二者 |

> **资料来源**：以上 2.3 全节主要依据 Famitsu 连载考据文【官方媒体/准官方】[《第七霊災とは何だったのか？（２）》](https://www.famitsu.com/matome/ff14/world3.html)。文中亦收录吉田直树的访谈：巴哈姆特身上的**金色拘束具**是亚拉戈封印技术的残留，所以才呈现金色。

### 2.4 路易索瓦与「十二神之力」

- **路易索瓦·露维耶**：夏雷安出身的贤者，**救世诗盟（Circle of Knowing）**盟主。第七灵灾中以十二神之力短暂束缚巴哈姆特，失败后将冒险者送往未来，自身消失。
- **十二神（The Twelve）**：艾欧泽亚的十二位守护神。1.0 终章中，十二神的力量被大量水晶以太"降神"至地上，形成蓝色光之锁链束缚巴哈姆特；虽然再封印失败，但**成功避免了艾欧泽亚被完全消灭**（代价是部分都市国家如霍兹亚要塞等被蒸发）【社区整理·Famitsu 考据】。
- **后续呼应**：Final Coil of Bahamut（2.4）中，路易索瓦以蛮神**菲尼克斯（Phoenix）**之姿重现；其孙**阿尔菲诺**与**阿莉塞**在 2.0 登场，是其直系血亲【官方设定】。

### 2.5 世界为何"遗忘"了光之战士⚠️

2.0 开场即点明这一设定【官方/游戏内文本，[ffxivstory 2.0 开场](https://ffxivstory.net/story/a_realm_reborn/68/)】：

- 第七灵灾后，**所有人的灵灾记忆都变得模糊**（"第七霊災の後遺症"）。
- 唯一确定的是"曾有英雄为拯救世界而战"，但**没人能想起他们的面容**——"如同强烈日光下的影子一般不可见"。
- 因此人们把这些无名救世主称为 **「光之战士」（Warrior of Light / 光の戦士）**。
- 1.0 玩家角色被路易索瓦送往 5 年后；1.0 的"Legacy"玩家在 2.0 中即扮演"回归的光之战士"，新玩家则扮演继承其名号的新英雄。

## 三、2.0《新生艾欧泽亚》基础主线（2013-08-27）

### 3.1 开场：陆行鸟货车与「超之力」的梦

1. **梦境**：主人公梦见自己手持光之武器，与一名**假面黑衣人（无影拉哈布雷亚）**对峙——正欲讨伐时醒来。
2. **陆行鸟货车**：主人公是新人冒险者，坐在前往三国之一的**陆行鸟货车车台**上。同乘者（如前往格里达尼亚的**布雷蒙达**）会讲解世界局势：灵灾伤痕未愈、冒险者仍被需要、魔物再度凶暴化。
3. **抵达与登记**：途中被卷入与蛮族（如伊克萨尔族）的战斗，抵达都市后在冒险者公会完成登记，第一步正式迈出。
4. **「超之力」说明**：**敏菲利亚**在砂之家向主人公解释「超之力」——跨越精神之壁、看见真相的力量；能跨越时间与心之壁。主人公的超之力**尤其擅长跨越时间**（可窥见过去）【社区整理·[ffxivstory「暁の血盟」](https://ffxivstory.net/story/a_realm_reborn/550/)】。

### 3.3 拂晓血盟（第七黎明 / Scions of the Seventh Dawn）的成立【官方/游戏内文本】

拂晓血盟由**两个组织在第七灵灾后合并**而成（雅·修特拉在 2.0 中亲口说明）：

| 前身 | 日文名 | 性质 | 代表人物 |
| --- | --- | --- | --- |
| **救世诗盟 / 圆环之识**（Circle of Knowing） | 救世詩盟 | 夏雷安出身的学者集团，为拯救艾欧泽亚留在大陆 | **路易索瓦**、**雅·修特拉**、**于里昂热**、**帕帕力莫**、**伊达** |

- **目标**：解决蛮神问题、拯救艾欧泽亚；独立于三国，但与各军民团有交涉能力。

### 3.7 2.0 主线流程（因果链）

1. 到达三国之一 → 公会登记 → 三座迷宫（**萨斯塔沙**、**塔姆塔拉墓所**、**铜铃矿山**）→ 证明实力
2. 乌尔达哈被**拂晓血盟**劝诱入盟 → 得到砂之家据点 → 接受阿马尔贾族调查委托
3. 与**桑克瑞德**合作讨伐**伊弗利特** → 名声传遍三国 → 加入一国军民团
4. 希尔芙族/拉姆问题调查 → 与帝国密探、无影的暗流接触
5. 无影调查：**小阿拉米格**（受无影煽动的年轻人企图召唤蛮神对抗帝国）→ **豪凯宅邸**（达尔坦库尔家悲剧，少女化为魔物）→ 与两名无影照面
6. 经由"英雄公司"接触科波德族 → 讨伐**泰坦**
7. **砂之家遭帝国袭击**：大量同伴被杀，**敏菲利亚、塔塔露、帕帕力莫、于里昂热被俘**
8. 依照敏菲利亚的传话前往**圣阿达曼·兰达曼教会** → 与**阿尔菲诺**会合 → 阿尔菲诺识破失忆男子正是传说中的机工师**西德**
9. 前往库尔扎斯 → **石卫城（Stone Vigil）** → 取得飞空艇**企业号**并修复
10. 穿越迦楼罗的暴风 → 讨伐**迦楼罗** → **盖乌斯现身**，吸收蛮神之力，**复活究极神兵**
11. 与失散的**伊达、雅·修特拉**重逢 → 潜入**卡斯特鲁姆·森特里**救出敏菲利亚一行 → 拂晓血盟重建
12. **Operation Archon**：攻略**卡斯特鲁姆·梅里迪亚努姆** → 突入**普拉耶托里姆**
13. 盖乌斯启动究极神兵最终形态 → 主人公获**海德林的加护**剥离蛮神之力 → **拉哈布雷亚**介入，发动究极魔法
14. 主人公以羁绊之力击破**究极神兵**与**拉哈布雷亚** → 第七灵灾时代终结，**第七星历开始**

**叙事要点（依据中文详细战报）**：泰勒吉刻意制造"冒险者与娜娜莫独处"的局面以栽赃；罗罗力特（沙蝎众议长）实际并未被架空——娜娜莫的女仆与伊尔伯德都是他的人，他早算到泰勒吉会得意忘形而遭劳班斩杀、伊尔伯德可借此重创劳班；罗罗力特事后只"啧"了一声而非大笑，暗示其目的另有其他【社区整理·[新浪游戏《最终幻想14国际服2.55剧情》](http://games.sina.cn/gz/ff/2015-04-08/details-icczmvun8755103.d.html)】。
**⚠️ 后续揭示（3.x 剧透）**：娜娜莫并未死亡。后续《苍天之伊修加德》剧情揭示，她被投入假死状态的药物（而非致命毒药），长期隐匿，最终复归——政变的真相是罗罗力特以"假杀"换取瓦解共和派激进派与重塑乌尔达哈政局的筹码【社区整理/需以游戏内文本为准】。
**命名勘误**：任务中并无名为《A Requiem for Heroes》的 2.x 补丁——该标题属于 **4.5x《英雄的镇魂歌》**（Stormblood 末期）。2.55 的收束任务是**「Before the Dawn（希望の灯火）」**。
