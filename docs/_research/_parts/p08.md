### 8.1 概念分层

| 层级 | 定义 | 举例 |

| 地区 Region | 剧情/地理大区 | 萨纳兰、拉诺西亚、诺弗兰特、尤卡图拉尔 |
| 地图区 Zone | 玩家可自由移动的一张地图 | Western Thanalan、Lakeland |
| 主城 / 据点 Hub | 有完整服务功能（任务/市场/旅馆/行会）的城市 | 格里达尼亚、水晶都、图莱尤拉、Solution Nine |
| 副本 Dungeon | 实例化线性战斗地图 | Sastasha、The Clyteum |
| 讨伐 Trial | 单个 BOSS 的实例化战斗 | 伊弗利特讨伐战、The Unmaking |
| 大型任务 Raid | 8 人 / 24 人系列战斗 | 阿卡狄亚、水晶塔 |
| 探索型地图 Field Operation | 独立的持久化开放战斗地图 | 优雷卡、波兹雅、**Occult Crescent** |
| 深层迷宫 Deep Dungeon | Roguelike 随机楼层 | 死者宫殿、**Pilgrim's Traverse** |

### 8.4 内容节奏规律（可直接建模为"内容通胀曲线"）

| 规律 | 具体表现 |
|---|---|
| **副本数在 5.0 后固定为每版本 13 个** | ARR 31 → HW 18 → SB 15 → ShB 13 → EW 13 → DT 13；5.0 起取消 Hard Mode |
| **讨伐数稳定在每版本约 15 个**（标准 7–9 + 高难度 7–8）| 几乎不随版本膨胀 |
| **8 人 raid 严格每版本 12 个**（3 tier × 4）| FF14 最稳定的内容节奏 |
| **团本严格每版本 3 个** | 6 版本 × 3 = 18 |
| **绝境战约每 2 年 1 个**，7.x 提速到 2 个 | 与大版本节奏解耦 |
| **深层迷宫固定落在每版本的 x.35** | 3.35 / 4.35 / 6.35 / 7.35（**5.0 缺位**）|
| **野外 zone 稳定在每版本 6–7 张** | ARR 例外（18+，因为是"从零建世界"）|

> 1. **7.1–7.5 完全没有新增传统野外 zone**。若按原任务书字面列举"6.x 虚无界、7.x 新区域"来建关卡表，会产生**"幽灵地图"**——虚无界的 The Fell Court of Troia、Alzadaal's Legacy 等**都是副本或剧情场景，不是开放地图**。

### 8.6 地图设计要素清单

#### 8.6.1 传送与移动

| 要素 | 说明 |
|---|---|
| **以太之光 Aetheryte** | 主水晶（大）与以太网小水晶（Aethernet）两级；共鸣后可传送 |
| **以太网 Aethernet** | 主城内部的快速移动网络 |
| **陆行鸟运输** | Chocobo Porter，城内/城际定点移动 |
| **船 / 飞空艇** | 跨大陆移动；金碟从三城邦可乘飞空艇 |

| **飞行解锁（2.0 地图）** | 完成主线 **"The Ultimate Weapon"** |
| **潜水** | 任务 **"In Soroban We Trust"** 解锁；5.0 起所有坐骑默认支持 |

#### 8.6.2 地图内容密度要素

| 要素 | 说明 |
|---|---|

#### 8.6.3 天气与昼夜（放置游戏"定时挂机"的核心参考）★

| 项目 | FF14 行为 |
|---|---|
| 游戏内一天 | 约 **70 分钟**真实时间（待核精确值）|
| 天气切换 | 按天气周期整体刷新，每周期约 **23 分 35 秒**；每个 zone 有独立天气表与概率权重 |
| 天气种类 | 晴 Fair Skies、阴 Cloudy、雾 Fog、雨 Rain、雷雨 Thunderstorms、雪 Snow、暴雪 Blizzards、强风 Winds、沙尘 Dust Storms、热浪 Heat Waves、灵气异常（Umbral/Astral）等 |
| 天气影响 | ① 特殊怪刷新（优雷卡 mutate）；② 钓鱼（特定鱼只在特定天气咬钩）；③ 采集限时点；④ S 级狩猎怪触发条件；⑤ 部分 FATE 与任务 |
| 昼夜影响 | ① 优雷卡 mutate（如"夜晚"条件怪）；② 部分 S 怪；③ 部分鱼类；④ 视觉表现 |
| 天气预报 | 官方提供"天气预报"功能，可查任意 zone 的未来天气，玩家据此排程 |

**门控类型抽象模板**：

| 门控类型 | FF14 原型 | 放置游戏实现 |
|---|---|---|
| 纯随机 | 普通 FATE 刷新 | 每 N 分钟按概率触发地图事件 |
| 时间窗 | 夜晚怪、夜间鱼 | 服务器时间落在 [T1,T2] 时才可能刷新 |
| 天气窗 | 暴雪怪、雨天鱼 | 地图天气状态机命中指定状态时刷新 |
| 时间 + 天气复合 | 优雷卡"夜晚 + 雷"的特殊怪 | 两个状态同时命中，稀有度提升 |
| 前置链式 | S 级狩猎怪（需先完成特定 FATE / 击杀特定怪）| 地图内进度条达标后解锁隐藏 BOSS |

#### 8.6.4 狩猎怪 Hunt Marks 的分级矩阵

| 等级 | 刷新方式 | 队伍规模 | 地图分布 |
|---|---|---|---|
| **B 级** | 固定刷新点，击杀后固定 CD 重生 | 单人可打 | 每张野外 zone 1 个固定点 |
| **A 级** | 固定刷新点，击杀后固定 CD 重生（通常数小时）| 3–8 人 | 每张野外 zone 1–2 个点 |
| **S 级** | **条件触发**：特定天气 / 时间 / 前置 FATE / 前置击杀 / 上交物品 | 满编团队（24+）| 每张野外 zone 1 个隐藏点位 |

> 📌 **启示**：Hunt Marks 用**极低的美术成本**在每张地图上塞进 **3 档难度 × 3 档人数**的可重复内容。

#### 8.6.5 zone 解锁规则（可直接实现）

```
zone_unlock(zone)   = MSQ_stage >= X AND player_level >= L_zone_min
zone_max_level(zone)= L_zone_max          # 决定该图的 EXP 衰减
zone_teleport(zone) = has_attuned_aetheryte(zone)
zone_flying(zone)   = aether_currents_collected(zone) == 5
```
