## 1. 世界观骨架

### 1.1 层级结构总览

FFXIV 的世界观可以按"宇宙 → 星球 → 世界 → 大陆 → 区域 → 地图区块"六层理解：

| 层级 | 名称 | 说明 |
|---|---|---|
| 宇宙 | — | 存在多个星球；本作舞台为其中一颗（其真名即"海德林"） |
| 星球 | 海德林 Hydaelyn（星球名） | 玩家所称"海德林"在设定上有**双重含义**：既是**星球/世界本身的名字**，也是**母水晶 Hydaelyn 的名字**（详见 1.6） |
| 世界 | 原初世界 Source + 十三个镜像世界 | 古代被"分裂"（Sundering）为十四个世界 |
| 大陆 | 三大洲：阿尔德纳德大陆 Aldenard、欧萨德大陆 Othard、图拉尔大陆 Tural（+ 北方空域 Northern Empty、南方大陆等）| |
| 区域 | 艾欧泽亚 Eorzea、伊修加德、阿拉米格、多玛、萨维奈、加雷马、诺弗兰特、尤卡图拉尔… | |
| 地图区块 | Central Shroud、Western Thanalan、Lakeland… | 玩家实际移动的 Zone |

### 1.2 原初世界与镜像世界【官方】

| 概念 | 英文 | 说明 |
|---|---|---|
| 原初世界 | The Source | 玩家所在的主世界，即"海德林"星球本身 |
| 镜像世界 | The Reflections / Shards | 十三（或十四减一）个平行世界，由古代世界的"分裂"产生 |
| 第一世界 | The First | 《暗影之逆焰》舞台；大陆名 **诺弗兰特 Norvrandt**；曾被"光之泛滥"吞没 |
| 第四世界 | The Fourth | 《Evercold》（8.0）舞台；被"冰之灾厄 Calamity of Ice"覆盖 |
| 第十三世界 | The Thirteenth | 即 **虚无界 The Void**；被"暗之泛滥"吞没，成为妖异（Voidsent）的巢穴 |
| 虚无界 | The Void | 第十三世界的现状；6.x「虚无界篇」主线舞台 |
| 世界合并 | Rejoining | 无影的终极目标：通过引发灵灾，把镜像世界与其居民"合并"回原初世界 |
| 世界分裂 | The Sundering | 古代由"海德林"一方执行的分裂行为，把完整的古代世界拆为十四份 |

**灵灾（Calamity）与属性对应**：每次世界合并都需要在原初世界引发一场大规模的属性灾变，即"灵灾"。已知有**七次灵灾**（第七灵灾 = 1.0 结局的卫月坠落）。灵灾按以太六属性轮转。

| 灵灾 | 属性（对应） | 备注 |
|---|---|---|
| 第一灵灾 | 风 | 传说中的上古灾厄 |
| 第二灵灾 | 雷 | — |
| 第三灵灾 | 火 | — |
| 第四灵灾 | 土 | — |
| 第五灵灾 | 冰 | — |
| 第六灵灾 | 水 | 玛哈文明的覆灭相关 |
| 第七灵灾 | 星极/灵极失衡（卫月坠落） | 1.0 结局；加雷马第七军团与卫月 Dalamud 坠落 |

> 说明：灵灾与属性的完整一一对应在不同资料与资料集之间存在细节差异，**建议在设计玩法时只使用"七次灵灾 + 六属性"这个骨架**，不必绑定具体对应关系。【社区／存疑】

### 1.3 以太 Aether 与六属性【官方】

FFXIV 的"物理引擎"是以太学：

| 概念 | 英文 | 说明 |
|---|---|---|
| 以太 | Aether | 构成万物的能量；空气、大地、生物体内皆含以太 |
| 六属性 | Fire / Ice / Wind / Earth / Lightning / Water | 火、冰、风、土、雷、水。**注意：冰（Ice）而非"冰=水"** |
| 星极 | Astral | "活性"侧；星极属性表现为激烈、外向、破坏 |
| 灵极 | Umbral | "惰性"侧；灵极属性表现为静止、内敛、储存 |
| 无属性 | — | 少量素材/技能不属六属性 |
| 光 / 暗 | Light / Dark | **不是六属性之一**，而是以太"状态"的极端：光的极端 = 停滞与永不变质（第一世界的光之泛滥即"世界被冻结在完美中"），暗的极端 = 崩坏与虚无（第十三世界） |
| 精炼 | Tempering | 蛮神对接触者的精神支配，属以太层面的洗脑 |
| 以太枯竭 | Aetherial depletion | 蛮神持续吸收周围以太导致土地贫瘠 |

**对放置游戏的意义**：六属性是天然的"元素相克/技能树/关卡主题"骨架，且与灵灾、蛮神、地图主题一一对应，**复用成本极低**。
