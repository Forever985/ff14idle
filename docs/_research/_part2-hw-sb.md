## 1. 总览：两个资料片的定位

| 项目 | 苍天之伊修加德 Heavensward | 红莲之狂潮 Stormblood |
|---|---|---|
| 版本区间 | 3.0（2015-06-23）– 3.5（2017-01-17） | 4.0（2017-06-20）– 4.56（2019-04-02） |
| 等级上限 | 50 → **60** | 60 → **70** |
| 新职业 | 暗黑骑士、占星术士、机工士 | 赤魔法师、武士（4.5 追加青魔法师·限定职业） |
| 新种族 | 傲龙族 Au Ra（晨曦之民 Raen / 暮晖之民 Xaela） | —（无新种族） |
| 主舞台 | 伊修加德、德拉瓦尼亚、阿巴拉提亚 | 阿拉米格（基拉巴尼亚）+ 多玛（奥萨德远东） |
| 核心母题 | **真相与和解**：千年战争的谎言、人龙能否共存 | **解放与代价**：被压迫民族的独立、"解放之后怎么办" |
| 主要反派 | 教皇托尔丹七世、尼德霍格、圆桌骑士十二 | 芝诺斯·耶·加尔乌斯、芙朵拉、尤尤哈提/朝日、瓦里斯 |
| 关键新增系统 | 飞行坐骑、机工城亚历山大、24 人副本、深宫 | 游泳/潜水、跨服、欧米茄、重返伊瓦利斯、禁地优雷卡 |
| 官方专题页 | [Heavensward](https://eu.finalfantasyxiv.com/heavensward/) | [Stormblood](https://eu.finalfantasyxiv.com/stormblood/) |

【官方设定】3.0 官方站将"故事（Story）"的核心冲突概括为：光之战士与同伴们**终结了北境人与龙之间长达千年的纷争**；4.0 官方站则写明本作是"为阿拉米格与远东的自由而战、将加雷马帝国逐出"的旅程（[Heavensward 官网](https://eu.finalfantasyxiv.com/heavensward/)、[Stormblood 官网](https://eu.finalfantasyxiv.com/stormblood/)）。

## 2. 苍天之伊修加德 3.0 本体

### 2.1 版本表：3.0

| 条目 | 内容 |
|---|---|
| **版本号** | 3.0（2015-06-23） |
| **主题** | 苍天之伊修加德 / 龙诗战争的开端 |
| **核心冲突** | 被 2.5 乌尔达哈政变逐出城邦的光之战士一行，在伊修加德寻求庇护；同时被卷入"龙诗战争"这场持续千年的宗教战争，并逐步发现其**建立在弑亲与背叛之上** |
| **主要反派** | 教皇**托尔丹七世 Thordan VII**、苍天骑士团（Heavens' Ward）、**尼德霍格 Nidhogg**（邪龙）、异端者激进派 |
| **BOSS** | 讨伐战：罗波那 Ravana（Thok ast Thok）、俾斯麦 Bismarck（The Limitless Blue）、**圆桌骑士 Knights of the Round / 托尔丹王 King Thordan**（The Singularity Reactor）；大型任务：亚历山大·戈耳狄俄斯（A1–A4） |
| **关键转折点** | ① 得知伊修加德开国圣王托尔丹一世与十二骑士**杀害并分食了圣龙之妹"邪龙"拉塔托斯克 Ratatoskr**，夺取其眼；② 尼德霍格因此发动千年复仇；③ 教皇以**三斗神（Warring Triad）**为媒介实现"请神"，自身化为蛮神；④ 阿莉塞（Alisaie）正式登场 |

### 2.2 关键设定与角色（3.0）

| 名词 | 中文/说明 | 要点 |
|---|---|---|
| 伊修加德 Ishgard | 山岳城邦，哈罗尼教（Halonic Orthodoxy）神权国家 | 与龙族交战千年；由**教皇 + 四大名门（Fortemps / Durendaire / Dzemael / Haillenarte）**统治 |
| 龙诗战争 Dragonsong War | 伊修加德 vs 龙族 | 名义上是"圣战"，实质是**人先弑龙**的复仇循环 |
| 托尔丹七世 Thordan VII | 教皇、最终化为蛮神 | 以阿济兹拉（Azys Lla）的**三斗神**装置为核，召唤出"圆桌骑士十二"并**自身成神** |
| 苍天骑士团 Heavens' Ward | 教皇亲卫"圆桌骑士十二" | 战斗中与托尔丹一同以蛮神形态再现 |
| 埃斯蒂尼安 Estinien Wyrmblood | 苍天龙骑士 | 背负**尼德霍格之眼**的复仇者；3.3 被尼德霍格夺舍 |
| 雅·修特拉 / 艾丝蒂尼安 · 艾默里克 Aymeric | 神殿骑士团总长 | 改革派核心，力主人龙和解 |
| 伊塞勒 Ysayle / 冰之心 Iceheart | 异端者领袖 | 具**回响**、可召唤**希瓦 Shiva**；真实目的在 3.3 揭晓 |
| 圣龙赫拉斯瓦尔格 Hraesvelgr | 拉塔托斯克与尼德霍格之兄 | 曾与人相恋，对人与龙皆失望；保管着"真相" |
| 邪龙拉塔托斯克 Ratatoskr | 被人类杀害的龙 | 其眼被夺取 → 尼德霍格复仇的根源 |
| 阿莉塞 Alisaie | 阿尔菲诺之妹 | 追问祖父路易索瓦的遗产；3.4 起加入拂晓 |
| 阿尔菲诺 Alphinaud | 拂晓血盟 | 因水晶义勇队背叛而重挫，伊修加德篇中重新成长 |
| 三斗神 Warring Triad | 赛菲罗斯 / 索菲亚 / 祖尔宛 | 亚拉戈帝国封印的美拉西迪亚蛮神，3.2/3.4/3.5 依次解封 |

【官方设定】3.0 与 3.5 官方站均确认：**阿济兹拉（Azys Lla）** 是光之战士与**教皇托尔丹七世**对决、并目睹其"成神"的舞台（[3.1 官方专题](https://eu.finalfantasyxiv.com/pr/special/3_1_As_Goes_Light_So_Goes_Darkness/)）。
【社区整理】埃斯蒂尼安在 3.0 结尾于**神域浮岛（The Aery）**击杀尼德霍格并取得其双眼，这构成了 3.3 "龙之复仇"直接伏笔。

### 2.3 3.0 主要迷宫（副本）

【社区整理】Dusk Vigil、Sohm Al、The Aery、**The Vault（宝座之间 · 3.0 剧情转折点）**、The Great Gubal Library。

### 3.1 Patch 3.1 · As Goes Light, So Goes Darkness（2015-11-10）

| 条目 | 内容 |
|---|---|
| **版本号** | 3.1 |
| **主题** | 光明逝去，黑暗降临 |
| **核心冲突** | 真相动摇国教根基后的**伊修加德内乱**：否定真相者与拥抱真相者的分裂 |
| **主要反派** | 伊修加德保守派贵族、异端者残党、无影（幕后） |
| **BOSS** | 吟游诗人叙事诗：**托尔丹的统治（Thordan's Reign）**；24 人副本：**虚空方舟 The Void Ark**（Boss：Deathgaze Hollow → Irminsul & Ferdiad → Cuchulainn → Echidna） |
| **关键转折点** | ① 伊修加德被迫面对"千年圣战源于弑亲"的事实；② 与龙族和解迈出第一步；③ 暗之战士（Warriors of Darkness）**首次现身**预告 |

【官方设定】官方 3.1 专题写明：从阿济兹拉归来后，伊修加德举国信仰动摇——"为千年而战、笃信正义的人，忽然被告知圣战诞生于血与背叛"；并列举新内容为**虚空方舟（24 人）、圣莫西安植物园、法罗斯天塔（Hard）、云海探索"迪亚德姆 The Diadem"、吟游诗人叙事诗：托尔丹的统治、圣恩达利姆神学院支线、魂灵武器（Anima）**（[3.1 官方专题页](https://eu.finalfantasyxiv.com/pr/special/3_1_As_Goes_Light_So_Goes_Darkness/)）。

## 8. 跨资料片对照与易错点勘误

### 8.1 双资料片结构对照

| 维度 | 苍天篇（3.x） | 红莲篇（4.x） |
|---|---|---|
| 叙事驱动 | **揭露历史真相** → 迫使社会自我修正 | **推翻外来统治** → 面对"解放之后"的现实 |
| 反派性质 | 宗教权威的**内在腐败** + 龙族的**外部复仇** | 帝国的**外部压迫** + 被殖民者内部的**撕裂** |
| 最"人"的反派 | 托尔丹七世（以信仰包装私欲） | 芙朵拉、尤尤哈提（都是被压迫环境的产物） |
| 收束方式 | 3.3 千年战争终结 → 3.5 视线转向帝国 | 4.0 阿拉米格/多玛双解放 → 4.5 帝国全面反扑 |
| 留给下一资料片的钩子 | 神龙被封印、拂晓解散、帝国阴影 | 拂晓灵魂被夺、水晶公召唤、第一世界 |

### 8.2 易错点勘误清单

| 常见误记 | 正确说法 |
|---|---|
| "Sephirot 是 3.3 的 BOSS" | **Sephirot = 3.2**（Containment Bay S1T7）；3.3 = **Nidhogg**；3.4 = **Sophia**；3.5 = **Zurvan** |
| "Zurvan 是第一个三斗神" | 顺序为 **Sephirot（3.2）→ Sophia（3.4）→ Zurvan（3.5）**，Zurvan 是**最后一柱** |
| "4.0 有 Nier 联动 24 人副本" | **Nier（寄叶异闻录：黑暗天启）是 5.0/5.1/5.3 的内容**，属 Shadowbringers，不在 4.x |
| "哈迪斯 Hades 是 4.x 讨伐战" | **哈迪斯是 5.0 的最终讨伐战**，4.5 只完成**艾梅特赛尔克的身份揭示** |
| "4.4 里的芝诺斯活着回来了" | 4.4 的"芝诺斯"是**艾里迪布斯伪装**；真芝诺斯肉体在 4.0 皇家动物园已死 |
| "The Final Steps of Faith 是 2.x 内容" | 2.x 的对应内容是 **The Steps of Faith（信仰之战）**；**The Final Steps of Faith（信仰的尽头）是 3.3 的尼德霍格讨伐战** |
| "蛇之环的 BOSS 是须佐之男" | **The Wreath of Snakes 的 BOSS 是青龙 Seiryu**（4.5） |
| "欧雷卡 Eureka 是副本 BOSS 列表的一部分" | **优雷卡是"禁地（Field Operation）"探索内容**，应单列，不属讨伐战/大型任务 BOSS 表 |
| "3.4 已完整解释暗之战士的来历" | 3.4 只给出**暗示与悬念**，完整解释在 **5.0** |
| "4.5 已揭示水晶公就是古·拉哈·提亚" | 4.5 仅出现**"水晶公的召唤"**，身份在 **5.0** 才揭晓 |
