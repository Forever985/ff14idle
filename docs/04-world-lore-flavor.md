## 1. 世界观骨架

### 1.1 层级结构总览

FFXIV 的世界观可以按"宇宙 → 星球 → 世界 → 大陆 → 区域 → 地图区块"六层理解：

| 层级 | 名称 | 说明 |
|---|---|---|
| 宇宙 | — | 存在多个星球；本作舞台为其中一颗（其真名即"海德林"） |
| 星球 | 海德林 Hydaelyn（星球名） | 玩家所称"海德林"在设定上有**双重含义**：既是**星球/世界本身的名字**，也是**母水晶 Hydaelyn 的名字**（详见 1.6） |
| 世界 | 原初世界 Source + 十三个镜像世界 | 古代被"分裂"（Sundering）为十四个世界 |
| 大陆 | 三大洲：阿尔德纳德大陆 Aldenard、欧萨德大陆 Othard、图拉尔大陆 Tural（+ 北方空域 Northern Empty、南方大陆等）| |
| 区域 | 艾欧泽亚 Eorzea、伊修加德、阿拉米格、多玛、萨维奈、加雷马、诺弗兰特、尤卡图拉尔… | |
| 地图区块 | Central Shroud、Western Thanalan、Lakeland… | 玩家实际移动的 Zone |

### 1.2 原初世界与镜像世界【官方】

| 概念 | 英文 | 说明 |
|---|---|---|
| 原初世界 | The Source | 玩家所在的主世界，即"海德林"星球本身 |
| 镜像世界 | The Reflections / Shards | 十三（或十四减一）个平行世界，由古代世界的"分裂"产生 |
| 第一世界 | The First | 《暗影之逆焰》舞台；大陆名 **诺弗兰特 Norvrandt**；曾被"光之泛滥"吞没 |
| 第四世界 | The Fourth | 《Evercold》（8.0）舞台；被"冰之灾厄 Calamity of Ice"覆盖 |
| 第十三世界 | The Thirteenth | 即 **虚无界 The Void**；被"暗之泛滥"吞没，成为妖异（Voidsent）的巢穴 |
| 虚无界 | The Void | 第十三世界的现状；6.x「虚无界篇」主线舞台 |
| 世界合并 | Rejoining | 无影的终极目标：通过引发灵灾，把镜像世界与其居民"合并"回原初世界 |
| 世界分裂 | The Sundering | 古代由"海德林"一方执行的分裂行为，把完整的古代世界拆为十四份 |

**灵灾（Calamity）与属性对应**：每次世界合并都需要在原初世界引发一场大规模的属性灾变，即"灵灾"。已知有**七次灵灾**（第七灵灾 = 1.0 结局的卫月坠落）。灵灾按以太六属性轮转。

| 灵灾 | 属性（对应） | 备注 |
|---|---|---|
| 第一灵灾 | 风 | 传说中的上古灾厄 |
| 第二灵灾 | 雷 | — |
| 第三灵灾 | 火 | — |
| 第四灵灾 | 土 | — |
| 第五灵灾 | 冰 | — |
| 第六灵灾 | 水 | 玛哈文明的覆灭相关 |
| 第七灵灾 | 星极/灵极失衡（卫月坠落） | 1.0 结局；加雷马第七军团与卫月 Dalamud 坠落 |

> 说明：灵灾与属性的完整一一对应在不同资料与资料集之间存在细节差异，**建议在设计玩法时只使用"七次灵灾 + 六属性"这个骨架**，不必绑定具体对应关系。【社区／存疑】

### 1.3 以太 Aether 与六属性【官方】

FFXIV 的"物理引擎"是以太学：

| 概念 | 英文 | 说明 |
|---|---|---|
| 以太 | Aether | 构成万物的能量；空气、大地、生物体内皆含以太 |
| 六属性 | Fire / Ice / Wind / Earth / Lightning / Water | 火、冰、风、土、雷、水。**注意：冰（Ice）而非"冰=水"** |
| 星极 | Astral | "活性"侧；星极属性表现为激烈、外向、破坏 |
| 灵极 | Umbral | "惰性"侧；灵极属性表现为静止、内敛、储存 |
| 无属性 | — | 少量素材/技能不属六属性 |
| 光 / 暗 | Light / Dark | **不是六属性之一**，而是以太"状态"的极端：光的极端 = 停滞与永不变质（第一世界的光之泛滥即"世界被冻结在完美中"），暗的极端 = 崩坏与虚无（第十三世界） |
| 精炼 | Tempering | 蛮神对接触者的精神支配，属以太层面的洗脑 |
| 以太枯竭 | Aetherial depletion | 蛮神持续吸收周围以太导致土地贫瘠 |

**对放置游戏的意义**：六属性是天然的"元素相克/技能树/关卡主题"骨架，且与灵灾、蛮神、地图主题一一对应，**复用成本极低**。

> 📌 **放置游戏建议**：
> 1. **不要**实现"种族数值差异"——原作在实用层面已经等于没有，硬做反而与设定不符。
> 2. **可以**实现"种族 → 起始天赋树/被动技能标签"的**弱差异**（例如森林之民 +采集速度、炎之民 +防御），并明确标注为**本作原创设计**而非原作还原。

> 1. **7.1–7.5 完全没有新增传统野外 zone**。若按原任务书字面列举"6.x 虚无界、7.x 新区域"来建关卡表，会产生**"幽灵地图"**——虚无界的 The Fell Court of Troia、Alzadaal's Legacy 等**都是副本或剧情场景，不是开放地图**。
> 2. 7.x 的新地图形态全部转向**独立实例化探索地图**（Occult Crescent / Cosmic Exploration / 深层迷宫）。
> 3. 6.x 同理：**虚无界篇没有新增开放野外地图**。

## 9. 面向"放置游戏"的可用性分析（设计层）

> 本节由设计侧补写（非调研事实），把前 8 章的设定**翻译成游戏系统**。
> 与 `10-design-blueprint.md` 的映射总表互为详略。

### 9.1 叙事资产 → 游戏结构

| FF14 叙事资产 | 放置游戏对应 | 说明 |
| --- | --- | --- |
| 资料片（2.0→8.0） | **大章** | 每章 10 级 + 120 iLvl（见 `11-content-inventory.md`） |
| 三大城邦 + 各资料片主城 | **章节枢纽/主界面场景** | 换章 = 换主城，天然的场景切换节奏 |
| 地图区域（每版 5–8 个） | **关卡分组** | 一张地图 = 一组关卡 |
| 蛮神 / 蛮族 | **章内 Boss 与支线势力** | 蛮神讨伐线是天然的"章中 BOSS" |
| 拂晓血盟成员 | **可收集的固定职业伙伴** | 对应官方 Duty Support 语义（见蓝图决策一） |
| 无影 / 帝国 / 各版反派 | **章节反派与后期 BOSS** | 主线推进的叙事钩子 |
| 主线任务链 | **关卡链 + 剧情文本** | 任务名可直接复用，是廉价而高效的内容来源 |

### 9.2 收藏系统 → 收集玩法（**FF14 的富矿**）

| FF14 收藏系统 | 数量级 | 放置游戏映射 | 建议加成 |
| --- | --- | --- | --- |
| **坐骑 Mounts** | 100+ | 收集图鉴 + 稀有掉落展示 | 小幅移速/收益加成 |
| **宠物 Minions** | 300+ | 图鉴收集（低成本高满足感） | 纯展示 + 图鉴进度奖励 |
| **乐谱 Orchestrion** | 100+ | 音乐解锁（须自制素材替代，见 `07` 法务） | 纯展示 |
| **九宫幻卡 Triple Triad** | 300+ 卡牌 | ⭐ **可做成独立小游戏**（卡牌对战本身即完整玩法） | 卡组强度 |
| **成就 Achievements** | 数千条 | 目标系统 | **永久小加成**（关键：否则无驱动力） |
| **称号 Titles** | 数百 | 展示型成就 | 纯展示 |
| **幻化 Glamour** | 海量外观 | 外观系统（长线留存点） | 纯展示 |
| **钓鱼图鉴** | 1000+ 鱼种 | ⭐ 收集向支线小玩法 | 图鉴进度奖励 |
| **观光笔记 Sightseeing Log** | 每图若干 | 地图探索收集（点击式） | 探索度奖励 |
| **冒险者铭牌 / 肖像** | — | 个人主页装扮 | 纯展示 |

> **设计要点**：收集品若**只有展示价值**，在放置游戏里留存贡献极低。
> 建议绝大部分收集品提供**永久、微小、不破坏平衡**的加成（如 +0.5% 产出），
> 并把"图鉴完成度"本身做成一个大成就——**这才是放置游戏收集系统的正循环**。

### 9.3 明确不适合直接搬的设定

| 设定 | 为什么不适合 | 替代做法 |
| --- | --- | --- |
| 3D 场景 / 副本实景 | 成本极高且不必要 | 文字 + 立绘 + 图标（wow-idle 已验证） |
| 房屋系统（摇号、装修） | 重交互、重资源 | 简化为"公会大厅"静态产出设施 |
| 麻将 / 赛马等硬核小游戏 | 实现成本高、与放置定位冲突 | 只保留"幻卡"这类可数值化的小游戏 |
| 玩家间真实交易 | 单机放置游戏无经济网络 | NPC 市场 + 价格波动模拟 |

### 9.4 一句话结论

**FF14 的设定与收藏系统是放置游戏最不需要发愁的部分**——官方已积累 13 年、
数千条成就、上千种收集品、明确的资料片章节结构。
真正的难点在**数值曲线、战斗抽象与合规边界**（见 `10` 与 `07`）。
